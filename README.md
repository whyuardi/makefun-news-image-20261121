A program that draws one image summing up the world's news of
**Saturday 21 November 2026** — a newspaper front page, drawn entirely
in code with Python + Pillow.

## The day's news

- **Lead: Russian missiles land in Poland** — a Kh-101 cruise missile
  came down in south-east Poland as Ukraine's allies drilled nearby.
  PM Donald Tusk called it a deliberate provocation; NATO jets were
  scrambled and alliance chief Mark Rutte was due in Warsaw.
- **Gen Z takes to Europe's streets** — thousands rallied in 25
  countries over living costs, military spending and climate.
- **Peru shaken by a 6.8 quake** — the Junín region hit; tremors felt
  320 km away in Lima.
- **COP31 deal stalls** — climate talks fail to agree a plan.
- **Denmark expels a Russian diplomat** — over an alleged plot to kill
  a US-Ukrainian rapper.
- **Trump to Nvidia: bring Huang back** — the president urges the chip
  giant to reinstate its ex-CEO and threatens a tax on AI data centres
  built abroad.
- Also: Nepal's PM heads to Delhi, KL Rahul completes the SENA set,
  Rikers Island to close by 2032, Houthi missiles downed.

## Run it

```sh
python3 render.py        # writes entry.png (1024x1024, < 1 MiB)
python3 main.py          # copies entry.png to /output/entry.png
```

No network, no randomness — two runs write the same bytes.
